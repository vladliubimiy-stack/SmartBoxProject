## Telegram-бот: runtime MQTT_HOST

При старте `tgbot/telebot_mqtt.py` запускается скрипт `tgbot/scripts/render_mqtt_env.py`, который перегенерирует файл `tgbot/.env.runtime` с актуальными значениями:

- `MQTT_HOST=<IPv4 адрес интерфейса>`
- `MQTT_PORT=1883`

### Как выбрать правильный адаптер (в т.ч. Windows)

Используйте переменную `MQTT_BIND_IFACE` в `tgbot/.env`:

- Linux: `MQTT_BIND_IFACE=wlan0` или `MQTT_BIND_IFACE=eth0`
- Windows: укажите имя адаптера, например `MQTT_BIND_IFACE=Ethernet 2` (поддерживается и полное имя вида `Адаптер Ethernet Ethernet 2`)

Если `MQTT_BIND_IFACE` не задан:

- на Linux скрипт сначала берёт интерфейс маршрута по умолчанию, потом первый non-loopback IPv4;
- на Windows/macOS используется fallback-определение IPv4.

Если IPv4 определить не удалось, бот не стартует молча: в лог пишется понятная ошибка и запуск останавливается.
